## Featured Project: Assignment 05

This assignment focuses on the application of Machine Learning in Sales Forecasting and Image Recognition. The general objective is to develop a practical project applying ML techniques in two distinct scenarios.

### Part 1: Sales Forecasting (Time Series)
The goal is to create a model to predict weekly or monthly sales based on historical data.

* **Tasks**: Includes data collection (e.g., Kaggle), cleaning, and preparation.
* **Analysis**: Exploratory data analysis focusing on trends and seasonality.
* **Modeling**: Implementation of an **LSTM** or **ARIMA** model.
* **Evaluation**: Assessment using specific metrics:
    * Root Mean Square Error: $$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$
    * Mean Absolute Error (MAE) and Mean Absolute Percentage Error (MAPE).

### Part 2: Image Recognition (Computer Vision)
This section involves training a simple Convolutional Neural Network (CNN) to classify images.

* **Dataset Selection**: Use of standard benchmarks such as CIFAR-10 or MNIST.
* **Preprocessing**: Implementation of normalization and Data Augmentation techniques.
* **Architecture**: Developed using TensorFlow/Keras or PyTorch.
* **Evaluation**: Metrics include Accuracy, Precision, and Recall.
