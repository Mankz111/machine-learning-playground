## Featured Project: Assignment 05

[cite_start]This assignment focuses on the application of Machine Learning in Sales Forecasting and Image Recognition[cite: 2]. [cite_start]The general objective is to develop a practical project applying ML techniques in two distinct scenarios[cite: 3, 4].

### Part 1: Sales Forecasting (Time Series)
[cite_start]The goal is to create a model to predict weekly or monthly sales based on historical data[cite: 7, 9].

* [cite_start]**Tasks**: Includes data collection (e.g., Kaggle), cleaning, and preparation[cite: 11, 12].
* [cite_start]**Analysis**: Exploratory data analysis focusing on trends and seasonality[cite: 13].
* [cite_start]**Modeling**: Implementation of an **LSTM** or **ARIMA** model[cite: 14].
* [cite_start]**Evaluation**: Assessment using specific metrics[cite: 15]:
    * Root Mean Square Error: $$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$
    * [cite_start]Mean Absolute Error (MAE) and Mean Absolute Percentage Error (MAPE)[cite: 15].

### Part 2: Image Recognition (Computer Vision)
[cite_start]This section involves training a simple Convolutional Neural Network (CNN) to classify images[cite: 17, 18].

* [cite_start]**Dataset Selection**: Use of standard benchmarks such as **CIFAR-10** or **MNIST**[cite: 19].
* [cite_start]**Preprocessing**: Implementation of normalization and **Data Augmentation** techniques[cite: 20].
* [cite_start]**Architecture**: Developed using **TensorFlow/Keras** or **PyTorch**[cite: 22].
* [cite_start]**Evaluation**: Metrics include Accuracy, Precision, and Recall[cite: 23].
